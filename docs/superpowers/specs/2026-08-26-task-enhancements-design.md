# easyNote 任务增强设计

## 范围

本次覆盖日期跨天刷新、双向多任务关联、列表优先级标识、开始日期、窄屏详情布局和富文本常用格式工具。

## 数据模型

`Task` 新增 `startDate: string` 与 `relatedTaskIds: string[]`。新建任务的开始日期默认当前本地日期，旧数据和导入数据缺失时从 `createdAt` 推导本地日期，关联列表缺失时使用空数组。

## 关联任务

详情编辑区提供全部任务的可搜索多选控件，排除当前任务。仓储层在创建和更新时维护双向关系，在删除任务时清理其他任务中的引用。详情区只渲染存在的关联任务；失效引用显示删除提示并可清理；点击有效项切换任务详情。

## 日期与视图

面板在跨越自然日时触发重新渲染，使计数和分组实时更新。日期比较统一采用本地日期，避免 UTC 转换造成偏差。

## 视觉与布局

任务列表通过高/中/低优先级色条和图标区分优先级，逾期状态保持独立的红色提示。详情栏在窄宽度下使用单列字段、可换行控件和合理的最小宽度，避免日期控件溢出。

## 富文本

在现有 Tiptap 配置中增加文字颜色、字号、下划线、删除线和四种对齐方式。颜色、字号采用下拉控件，对齐采用图标按钮，旧文档保持兼容。

## 错误处理与验证

非法关联 ID、当前任务自关联和不存在任务由仓储层拒绝或清理。实现完成后运行 `npm run typecheck`，不新增自动化测试。
