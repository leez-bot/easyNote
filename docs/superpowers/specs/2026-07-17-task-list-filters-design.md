# 任务列表紧凑筛选设计

## 目标

缩减“已完成”和“全部任务”视图中日期范围筛选的常驻宽度，新增实时标题搜索，并确保筛选无结果时仍可操作筛选条件。

## 交互

- 日期筛选只在“已完成”和“全部任务”视图提供。默认显示灰色日历图标；点击后在图标下方打开日期范围弹层。
- 日期范围被选中后，日历图标使用主题蓝色。弹层内提供“清空”操作，立即取消日期筛选。
- 搜索默认显示灰色搜索图标。点击后，右侧输入框以 CSS 过渡展开并自动获得焦点；标题关键词变更时立即筛选。
- 搜索关键词为空时，输入框收起为搜索图标；按 Escape 同样清空并收起。
- 日期范围和搜索关键词同时存在时，任务需要同时匹配两项条件。

## 实现边界

- 改动限定在 `src/renderer/features/tasks/TaskList.tsx` 与对应的 `src/renderer/styles/app.css`。
- `dateRange` 和 `searchKeyword` 均为 `TaskList` 内部瞬时 UI 状态，不写入 Zustand 或本地数据。
- 使用现有 Ant Design `DatePicker.RangePicker` 的弹层能力及 Lucide 图标，不新增依赖。
- 每一个 `orderedGroups` 分组都渲染标题与筛选操作。筛选后没有任务时，在未折叠的分组内显示空态文案，避免条件清除入口消失。

## 数据与错误处理

- 不修改共享模型、任务仓库、IPC 或数据文件。
- 仅按任务标题进行关键词匹配；搜索关键词会被 `trim` 并转为小写后比较。
- 日期范围规则保持当前语义：已完成视图按 `completedAt`（缺省使用 `updatedAt`），全部任务视图按 `createdAt`。
